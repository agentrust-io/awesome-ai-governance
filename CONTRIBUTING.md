# Contributing to Awesome AI Agent Governance

Thank you for helping improve the list. This page explains what can be listed, how to add an entry, and what we check before accepting it.

## Guidelines

### What belongs here?

The list covers everything involved in governing AI agents, meaning keeping them safe and being able to check what they did:

- Agent governance frameworks and control planes (software that checks an agent's actions against rules)
- LLM safety and guardrail tools
- Agent frameworks with governance features
- Standards and specifications that help agents from different vendors work together
- Observability and monitoring platforms for AI agents
- Security scanners and red-teaming tools (tools that run simulated attacks)
- Research papers and surveys on agent safety
- Industry reports and practical guides

### What doesn't belong?

- General AI/ML tools with no governance, safety or trust angle
- Tools that are unmaintained or archived
- Commercial products without a free tier, an open-source part, or a published specification
- Duplicate entries (check the existing listings first)

### How to contribute

1. Fork this repository
2. Add your tool in the appropriate category
3. Use the format: `- [Name](url) - One-line description of governance-relevant functionality.`
4. Keep descriptions short and neutral
5. Submit a pull request

### Quality standards

- The tool or resource must be actively maintained
- Open source is preferred, but notable commercial tools are accepted
- Research papers should come from peer-reviewed venues or established organizations
- Links must work
